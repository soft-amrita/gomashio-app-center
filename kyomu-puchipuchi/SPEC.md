# 虚無プチプチ無限工場
プチプチを潰す快感に特化したエンドレス暇つぶし。
## 機能
- グリッド表示の気泡（初期8列x8行程度）。タップ/クリックで潰れる（凹み表現＋Web Audio APIで短いノイズの「プチッ」音＋可能ならVibration APIで振動）
- 潰した気泡は少し待つと新しい気泡として復活する（無限に遊べる）
- 約1%でレア気泡：ハート型（絵文字表示）／黄金（金色）／爆発（周囲8個を一気に潰す）
- 潰した総数カウンタと、総数に応じた称号（例：0=見習い梱包員、100=梱包職人、500=気泡ハンター、1000=気泡の破壊神）

## 技術制約（全アプリ共通）
- index.html / style.css / app.js の3ファイルのみ。バニラJS/CSS、外部ライブラリ・CDN・外部フォント・外部画像は使わない
- スマホ/PC両対応のレスポンシブ、日本語UI
- フッターに「← ごましおアプリセンターに戻る」リンク（href="../"）
- データは外部送信しない
