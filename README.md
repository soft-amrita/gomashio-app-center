# ごましおアプリセンター (gomashio-app-center)

小さなウェブアプリをまとめたコレクション。トップページ（`index.html`）が「ごましおアプリセンター」として各アプリへリンクしています。

公開先: https://gomashio-app-center.pages.dev （Cloudflare Pages）

## 構成ルール

- アプリは1つずつサブフォルダに入れる（各フォルダがそのまま公開パスになる）
- 追加したらトップページのカードとこの一覧に1行足す
- すべて静的ファイルのみ（ビルドなし）、Cloudflare Pagesにそのままデプロイ
- 各アプリは `index.html` / `style.css` / `app.js` の3ファイル構成、外部ライブラリ・CDN・外部フォント禁止（詳細は `AGENTS.md`）

## 制作

企画はGeminiと相談、実装はCursor、運用は ごま（Muse）。
