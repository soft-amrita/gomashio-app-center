# 絶対押すなよボタン
押すたびにボタンが文句を言ったり逃げたりする、40段階のメタコメディ。
## 機能
- 画面中央に大きな赤いボタン「絶対押すなよ」。押した回数を表示
- クリックごとに段階が進み、40段階のリアクション（配列データで管理：文言＋効果）。効果の例：文言変化、震える、少し小さくなる/大きくなる、カーソルから逃げる（transform移動）、ダミーボタンが増える（本物だけカウント）、透明化しかける、傾く、落下して跳ねる、画面端に逃亡、色が変わる、等を組み合わせる
- 40段階に到達したら「ルール違反マスター認定証」カードを表示し、最初からボタンでリセット
- スマホでもタップで遊べる（逃げる挙動はタップ位置基準でも動くこと）

## 技術制約（全アプリ共通）
- index.html / style.css / app.js の3ファイルのみ。バニラJS/CSS、外部ライブラリ・CDN・外部フォント・外部画像は使わない
- スマホ/PC両対応のレスポンシブ、日本語UI
- フッターに「← ごましおアプリセンターに戻る」リンク（href="../"）
- データは外部送信しない
