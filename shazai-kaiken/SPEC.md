# 謝罪会見シミュレーター
日常のミスを記者会見風に謝罪するミニゲーム。
## 機能
- 入力：「やらかしたこと」（例：プリンを勝手に食べた）と名前（任意）
- 会見画面：ニュース番組風のテロップ（「○○氏、○○の疑い」）、記者からの質問がランダムに1つずつ表示される
- お辞儀ゲーム3回：長押し（タップ/マウス/スペースキー）でお辞儀角度ゲージが0→90度に進み、45度付近（許容範囲42〜48度）で離すと高評価。角度に応じて評価コメント
- お辞儀中はフラッシュ演出（画面の白フラッシュ＋Web Audio APIのシャッター音）
- 最終結果：「世間の納得度」を炎上／冷たい／まあ許す／感動した、等の段階で速報風に表示

## 技術制約（全アプリ共通）
- index.html / style.css / app.js の3ファイルのみ。バニラJS/CSS、外部ライブラリ・CDN・外部フォント・外部画像は使わない
- スマホ/PC両対応のレスポンシブ、日本語UI
- フッターに「← ごましおアプリセンターに戻る」リンク（href="../"）
- データは外部送信しない
