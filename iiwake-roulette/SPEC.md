# 限界言い訳ルーレット
遅刻・ドタキャンの言い訳をスロットで捏造する。
## 機能
- 3つのリール（誰が/何をして/どうなった）。スタートボタンで回転、各リールをストップボタンで止める（CSS/JSアニメーションで文字が流れる演出）
- 各リール8〜10種のワード（例：誰が=「電車が」「上司が」「猫が」、何をして=「止まって」「捕まって」「寝坊して」、どうなった=「遅れます」「行けなくなりました」）
- 結果を1文に組み立てて大きく表示＋誠意レベル★1〜5（ランダム＋組み合わせで決定）
- 言い訳をもとにした謝罪文テンプレートを自動生成し、コピーボタンを付ける
- 約5%で「確定演出」：画面が光り、絶対に許される最強の言い訳が固定表示される

## 技術制約（全アプリ共通）
- index.html / style.css / app.js の3ファイルのみ。バニラJS/CSS、外部ライブラリ・CDN・外部フォント・外部画像は使わない
- スマホ/PC両対応のレスポンシブ、日本語UI
- フッターに「← ごましおアプリセンターに戻る」リンク（href="../"）
- データは外部送信しない
