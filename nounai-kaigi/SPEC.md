# 脳内会議議事録メーカー
迷いごとを入力すると脳内の5人格が討論して結論を出す。
## 機能
- 議題を1行入力（例：「夜中にラーメンを食べるか」）→会議開始
- 5人格（理性・本能・怠惰・財布・謎の長老）がチャット風UIで順番に発言（各3〜4発言、テンプレート文に議題を差し込み、賛成/反対の立場を持つ）
- 発言ごとに賛成ゲージ/反対ゲージが変動する演出
- 最後に採決結果（可決/否決と一言コメント）を表示し、「脳内閣議決定書」をCanvasで画像化してダウンロード可能（議題・結果・日付・署名風テキスト）

## 技術制約（全アプリ共通）
- index.html / style.css / app.js の3ファイルのみ。バニラJS/CSS、外部ライブラリ・CDN・外部フォント・外部画像は使わない
- スマホ/PC両対応のレスポンシブ、日本語UI
- フッターに「← ごましおアプリセンターに戻る」リンク（href="../"）
- データは外部送信しない
