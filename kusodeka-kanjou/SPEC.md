# クソデカ感情変換器
一言テキストを特撮サブタイ風の極太明朝レイアウト画像に変換する。
## 機能
- テキスト入力（最大12文字程度）→Canvasに即時プレビュー
- レイアウト3種：横一文字ドン／縦書き＋横書き混在／斜めカットイン。黒背景に白と赤の極太明朝体（serif系フォント指定）
- 集中線エフェクトのON/OFFトグル、文字の大きさスライダー
- サイズ切替（正方形1080x1080／横長1200x630）でPNGダウンロード

## 技術制約（全アプリ共通）
- index.html / style.css / app.js の3ファイルのみ。バニラJS/CSS、外部ライブラリ・CDN・外部フォント・外部画像は使わない
- スマホ/PC両対応のレスポンシブ、日本語UI
- フッターに「← ごましおアプリセンターに戻る」リンク（href="../"）
- データは外部送信しない
