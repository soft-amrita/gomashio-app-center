# 深夜の飯テロ錬金術
食材を3つ選んで実在しないジャンクフードを錬成する。
## 機能
- 食材チップ12種（絵文字＋名前：マヨネーズ、ニンニク、チーズ、背脂、唐揚げ、チョコ、明太子、バター、ごはん、ポテト、深夜2時の空気、背徳感など）。タップで最大3つまで鍋に入る（選択中表示）
- 鍋のグツグツ揺れるCSSアニメーション。「錬成」ボタンで結果表示
- 結果：組み合わせから生成する料理名（食材名の合成＋修飾語辞書、例：「禁断のトリプル背脂マヨチーズ爆弾」）、推定カロリー（食材ごとの値＋深夜ボーナスで算出）、シズル感のある解説文（テンプレート数種）
- 選んだ食材の絵文字を大きく並べた「概念イラスト」表示

## 技術制約（全アプリ共通）
- index.html / style.css / app.js の3ファイルのみ。バニラJS/CSS、外部ライブラリ・CDN・外部フォント・外部画像は使わない
- スマホ/PC両対応のレスポンシブ、日本語UI
- フッターに「← ごましおアプリセンターに戻る」リンク（href="../"）
- データは外部送信しない
