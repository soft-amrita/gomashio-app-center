# 昭和家電たたき修理センター
砂嵐のブラウン管テレビを叩いて直す物理パズル風ゲーム。
## 機能
- Canvasで砂嵐（ホワイトノイズ）を描くテレビ画面。叩く（タップ/クリック、スワイプの速度で強さ判定）と画面が歪み、一瞬だけ映像が見える
- 「映り具合」メーター（0〜100）。叩く位置（右上寄りが効く等のスイートスポット）と強さで増減。弱すぎ/強すぎは逆効果
- 映り具合が高いほど映像（Canvasで描くレトロな図形＋「テストパターン」風や架空CMのテキスト）が長く見える
- 100到達でクリア：架空の昭和風CM（テキストと図形のアニメーション）を数秒流して「修理完了」表示。Web Audio APIで「バンッ」「ジジジ」という効果音

## 技術制約（全アプリ共通）
- index.html / style.css / app.js の3ファイルのみ。バニラJS/CSS、外部ライブラリ・CDN・外部フォント・外部画像は使わない
- スマホ/PC両対応のレスポンシブ、日本語UI
- フッターに「← ごましおアプリセンターに戻る」リンク（href="../"）
- データは外部送信しない
