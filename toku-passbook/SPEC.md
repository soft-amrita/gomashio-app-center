# 徳ポイント通帳
日常の善行・悪行をレトロな銀行通帳風に記帳し、来世ランクを表示する。
## 機能
- 通帳風UI：縦罫線のある明細表（日付・摘要・増減・残高）。新しい記帳が上部に印字アニメーションで追加される
- プリセットボタン12種（善行6・悪行6、例：「エレベーターの開ボタンを押した +50」「レジ横のチョコを衝動買い -20」など、文言は面白く）
- カスタム記帳：摘要テキスト入力＋数値入力（正負）で追加可能
- 残高に応じて「来世の転生先ランク」を表示（例：1,000以上=大富豪、500=社長、200=平社員、0=一般人、-200=カメ、-500=ミジンコ など6段階以上）
- localStorageに明細と残高を保存。全消去ボタンあり

## 技術制約（全アプリ共通）
- index.html / style.css / app.js の3ファイルのみ。バニラJS/CSS、外部ライブラリ・CDN・外部フォント・外部画像は使わない
- スマホ/PC両対応のレスポンシブ、日本語UI
- フッターに「← ごましおアプリセンターに戻る」リンク（href="../"）
- データは外部送信しない
