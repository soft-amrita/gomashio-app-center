# 社畜タイピング・エクソシズム
湧き出るビジネス用語の悪霊を連打で除霊する30秒ゲーム。
## 機能
- スタート画面→30秒のゲーム：画面内にビジネス用語（「お世話になっております」「なるはやで」「一旦持ち帰ります」など15種以上）の悪霊テキストが浮遊表示される
- PCはキー入力、スマホはタップ連打で攻撃。悪霊をタップ/ヒットで除霊するとパーティクル（Canvas）が弾ける
- 悪霊は時間とともに増える。除霊数＝スコア。終了後に「本日のストレス浄化率」とランクコメントを表示
- もう一度ボタンでリプレイ

## 技術制約（全アプリ共通）
- index.html / style.css / app.js の3ファイルのみ。バニラJS/CSS、外部ライブラリ・CDN・外部フォント・外部画像は使わない
- スマホ/PC両対応のレスポンシブ、日本語UI
- フッターに「← ごましおアプリセンターに戻る」リンク（href="../"）
- データは外部送信しない
