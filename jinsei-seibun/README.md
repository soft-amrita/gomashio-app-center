# 人生の成分表示

5つの質問に答えると、食品パッケージ裏面の「成分表示シール」風に、あなたの取扱説明書ラベルが生成される診断ジョークアプリです。

## 遊び方

1. タイトル画面で名前を入力（任意。空欄なら「ななしの人生」）
2. 「成分を調べる」を押して、全5問に回答
3. 結果画面で成分表示ラベルを確認
4. 「画像で保存」で PNG をダウンロード、「Xでシェア」で投稿画面を開く

## 技術構成

- `index.html` / `style.css` / `app.js` のみの静的サイト
- バニラ JavaScript / CSS（外部ライブラリ・CDN・外部フォント・外部画像なし）
- 回答データはブラウザ内のみで処理（外部送信なし）
- 同じ回答なら同じラベルになるよう、入力ハッシュで結果を決定的に生成

## 制作経緯

Gemini との相談で企画を固め、Cursor で実装しました。
