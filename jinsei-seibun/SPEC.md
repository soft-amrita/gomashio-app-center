# 人生の成分表示ジェネレーター 仕様書

Geminiとの相談で決まった企画。5つの質問に答えると、食品パッケージ裏面の「成分表示シール」風に、その人の取扱説明書ラベルが生成される診断ジョークアプリ。

## 技術制約
- 静的サイトのみ: `index.html` / `style.css` / `app.js` の3ファイル (+ このSPEC.mdとREADME.md)
- 外部ライブラリ・CDN・外部フォント・外部画像は一切使わない（バニラJS/CSSのみ、オフラインで動く）
- スマホ・PC両対応のレスポンシブ
- UIはすべて日本語

## 画面フロー
1. **タイトル画面**: アプリ名「人生の成分表示」、キャッチコピー、名前入力欄（任意。空欄なら「ななしの人生」）、「成分を調べる」ボタン
2. **質問画面**: 全5問を1問ずつ表示（進捗バー付き）。各問はタップ選択式またはスライダー式（下記）
3. **結果画面**: 成分表示ラベル + 「画像で保存」ボタン + 「Xでシェア」ボタン + 「もう一度」ボタン

## 質問（5問）とラベルへの反映
各回答はラベルの「原材料」や数値に変換される。変換先の文言はユーモア重視で、回答ごとに2〜3パターンのバリエーションを持たせ、入力のハッシュで決定的に選ぶ（同じ回答なら同じ結果）。

1. **休日の過ごし方は？**（選択式4択）
   - 布団と一体化 / 外へ飛び出す / 推し活に全振り / 気づいたら終わってる
   - → 原材料の主成分（例: 「布団への愛（国内製造）」「推しの尊さ」）
2. **カフェイン依存度は？**（スライダー0〜100、コーヒーカップが満ちていく演出）
   - → 添加物「カフェイン」の量と、成分表の「カフェイン含有率」
3. **スマホの充電が何%になると焦る？**（スライダー5〜95%）
   - → 「電池切れ恐怖症」の度合い、保存方法の文言に反映
4. **夜更かし度は？**（選択式4択）
   - 日付が変わる前に寝る / 1時くらいまで / 3時は余裕 / 朝日とともに寝る
   - → 添加物「夜更かし」、賞味期限の文言に反映
5. **人混みへの耐性は？**（選択式4択）
   - 祭り大好き / 普通 / できれば避けたい / 家から出たくない
   - → 「社交性」の%表示、取扱い上の注意に反映

## 結果ラベル（食品の成分表示シールをリアルに再現）
- 白地に黒枠、少し掠れた印刷風の質感（text-shadowや微妙な回転で「貼られたシール」感）
- 項目:
  - 品名: 「人生（○○風味）」※○○は回答から生成（例: 布団まみれ風味）
  - 名称: 「ヒト（成人型）」
  - 原材料名: 回答由来の材料を含有量順にスラッシュ区切りで5〜7個（例: 見栄（国内製造）、睡眠不足、推しの尊さ、現実逃避、やる気（微量））
  - 添加物: カフェイン、夜更かし、スマホ依存 など回答連動
  - 内容量: 「1名分」
  - 賞味期限: 回答連動のギャグ（例: 「布団の中であれば無期限」）
  - 保存方法: 「直射日光および急な電話を避け、布団の中で保存してください」系を回答で変化
  - 製造者: 「株式会社じぶん 本社：あなたの家」
  - 栄養成分表示風テーブル: エネルギー（やる気）kcal、たんぱく質→「根性」、脂質→「脂肪ではなく蓄え」、炭水化物→「言い訳」、食塩相当量→「周囲への塩対応」など、各0〜100の数値を回答から算出
  - バーコード: Canvasで描く。数字は回答内容のハッシュから生成する13桁
  - 注意書き小文字: 「※本製品は気分により性能が大きく変動します」系を1〜2行
- **ツヤ/ホログラム演出**: ラベル上に光沢グラデーションのレイヤーを置き、ポインタの位置（モバイルでは端末の傾き DeviceOrientation、許可が取れない場合はポインタのみ）に応じて光の帯が動く

## 画像で保存
- Canvasにラベル全体を再描画してPNG（1080px幅程度）をダウンロードできること。DOMの見た目と概ね同じレイアウト・文言で描く
- ファイル名: `jinsei-seibun.png`

## シェア
- 「Xでシェア」ボタン: 結果の要約テキスト（品名と原材料の先頭2つ程度）+ ハッシュタグ「#人生の成分表示」でXの投稿画面を開く（intent URL）
- 可能なら navigator.share も併用可（なくてよい）

## その他
- 回答データは外部送信しない（すべてブラウザ内処理）。その旨をフッターに一言
- 結果は回答のハッシュで決定的に生成（同じ入力→同じラベル）
- README.md: アプリの説明、遊び方、技術構成（バニラJS、外部依存なし）、制作経緯（Geminiと相談して企画、Cursorで実装）を簡潔に
